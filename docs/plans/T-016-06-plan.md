## Changes

### 1. `scripts/check-contrast.mjs` (CREATE, ~120 lines)
Mirror check-theme-tokens.mjs's structure and style exactly (same header comment format, parseScopes-style tokens.css parsing, table output, exit 0/1):
```js
#!/usr/bin/env node
/**
 * T-016-06 (F-TRF-016, FR-016-4 / AC-016-4): contrast CI check.
 *
 * Parses src/wa.web/src/styles/tokens.css (:root light default + html[data-theme='dark']) and computes the
 * WCAG 2.x relative-luminance contrast ratio for every text-on-background token pair in BOTH themes:
 *   - GATE tier (4.5:1 both themes): --fg, --fg-muted on --bg and --bg-subtle — body/label text everywhere;
 *     a new bad core pair fails CI before merge (US-016-03 Edge cases).
 *   - REPORT tier: --accent/--danger/--success/--warning (status text) + --fg-faint (weakest-token,
 *     placeholders/disabled only per F-TRF-016 UI notes) — printed with OK / AA-large(<4.5) / FAIL flags so the
 *     audit is re-runnable, not one-shot; light-theme status values below 4.5 are the known T-015-03 contract.
 *   - EXCEPTIONS: hardcoded #FFFFFF button text on --accent/--danger (index.css L100–101 documented contract) —
 *     asserted against the measured ratios so a token regression surfaces as an exception diff.
 * Prints the full ratio table; exits 0 on pass, 1 listing every gated failure.
 */
```
Behavior:
- Parse scopes exactly like check-theme-tokens.mjs (strip `/* … */` comments first — tokens.css carries per-token notes in them).
- WCAG relative luminance + contrast formula (the standard one; no dependency).
- GATE pairs (fail exit 1 if < 4.5 either theme): `--fg`/`--bg`, `--fg`/`--bg-subtle`, `--fg-muted`/`--bg`, `--fg-muted`/`--bg-subtle`.
- REPORT rows: every other fg/status token on both backgrounds, flagged OK / AA-large / FAIL.
- EXCEPTIONS list (asserted values): white-on-accent light 3.57 dark 2.81; white-on-danger light 4.40 dark 3.36 — assert each within ±0.05 of the computed value so a token change that breaks the documented contract fails loudly (the ratios are recomputed from tokens.css, not hardcoded as pass/fail).
- Header comment cites FR-016-4 + T-015-03's documented button contract, matching check-theme-tokens.mjs's citation style.
