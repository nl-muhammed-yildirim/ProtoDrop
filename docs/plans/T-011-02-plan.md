# T-011-02 — Audit write helper: `AuditLog` row + admin.action event (FR-011-5, TA-3.2/TA-5.3)

TASK: T-011-02 audit write helper — small wa.application component that writes one `AuditLog` row (ActorEmail, Action, EntityType, EntityId, DetailsJson per TA-3.2) AND emits the admin.action domain event { actor, action, entityType, entityId, details } (TA-5.3) in the same request; actor email passed explicitly so commands stay thin (TA-4.2a).
