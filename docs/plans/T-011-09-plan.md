## ASSUMPTIONS / DECISION
- DECISION (audit read surface): NEW separate read port IAuditReadStore rather than extending IAuditStore. Rationale: IAuditStore's doc pins it as "the audit row's only DB surface — one bounded insert per call" — a write port; adding GetRecentAsync muddies the read/write split the same way T-011-08 avoided (its DECISION created IAdminFlagStore instead of extending the read port IFlagsStore). If IAuditStore WERE extended, exactly ONE stub breaks: StubAuditStore in tests/wa.application.unit/Admin/AuditWriterTests.cs L96 (the only implementer outside src/wa.infrastructure/Persistence/AuditStore.cs, which would also need the new member). Cost of a separate port: one interface + one adapter file + one DI line.
- DECISION (suppression store surface): NEW IAdminSuppressionStore with both ListAsync and RemoveByIdAsync — no suppression store exists at all today (the inline blocks used raw db.Set), so there is nothing to extend; the mixed read+write shape mirrors IAdminUserStore (GetUsersAsync + SetPlanIdAsync).
- DECISION (audit payload): action "suppression.removed" (DECISION contract, task file step 1 — not enumerated in the spec); entityType "emailSuppression" (spec does not enumerate it either — lowercase entity name, consistent with transfer/user/flag siblings); entityId = id.ToString("n") (same as T-011-05/07/08); details = { email } where email is the REMOVED row's Address (captured pre-delete via the handler result — DECISION contract).
- DECISION (wire shapes): GET suppressions stays a bare array of { id, address, senderEmail, createdAtUtc } and DELETE success stays 200 OK — both pinned by UnsubscribeEndpointTests (L145, L179–L180); do NOT switch to NoContent like T-011-05/07. audit-recent is a new route: bare array of { id, actorEmail, action, entityType, entityId, detailsJson, createdAtUtc }, camelCase, no cursor (full CSV export is P1).
- ASSUMPTION: the App Insights telemetry.LogEvent(TelemetryEvents.AdminAction) line stays on DELETE success — it is T-006-03's FR-006-5 surface, distinct from this task's AuditLog row + admin.action event; both fire.
