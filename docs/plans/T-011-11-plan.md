- Endpoint 21 GET params: q (ONE param; server OR = LinkId exact CI OR EmailRecipient LIKE %q% — client sends whatever text is typed into one box), status (string word all/draft/active/expired/download_limit/deleted; absent = all; unknown = 400 VALIDATION), cursor, minBytes/maxBytes (pairing XOR — one without the other = 400), from/to (same pairing rule), limit (default 25; reject <=0 or >25 = 400). Malformed cursor = 400 VALIDATION.
- Endpoint 21 DELETE: /api/v1/admin/transfers/{id} — SuperAdmin-only (Operator = 403 FORBIDDEN via T-011-01 gate); null result (unknown/already-deleted) = 404 NOT_FOUND; success = 204 No Content, no body. EC-011-2: in-flight SAS may outlive the row — no client-side special handling.
