## ASSUMPTIONS / DECISION
- DECISION (store surface): NEW port IAdminFlagStore rather than extending IFlagsStore. Rationale: IFlagsStore is a READ port wrapped by FlagsCache (its doc says "Reads flag rows"); adding a write muddies it and breaks BOTH Limits test stubs (LimitsProviderTests.cs L244 + CachesTests.cs L150). The T-011-06/07 precedent is a dedicated admin-write surface over WaDbContext (IAdminUserStore, IAdminTransferStore) — no such flag store exists yet, so creating one mirrors T-011-05's option-(c): zero existing-stub breaks, reads stay on IFlagsStore (unchanged), writes go on IAdminFlagStore. Cost: one more file + one DI singleton line.
- DECISION (validation location/status): JSON-shape validation happens in the HANDLER (JsonDocument.Parse before any DB call) → 400 VALIDATION with message "Invalid JSON" (existing closed-list member, mirrors T-011-06/07 validation at Program.cs L531/L630). The endpoint reads the raw body string once and passes it through — keeps TA-4.2a thin (gate → Send → map → audit) and makes EC-011-4 unit-testable (bad JSON → ForInvalidJson, store not called). Order: validate JSON FIRST (cheap, no DB), then existence gate — so unknown-key + bad-JSON → 400 (both pre-commit, no audit row either way).
- DECISION (GET shape): bare JSON array of {key, value} — camelCase, ordered by key ascending, NO cursor/nextCursor (52 fixed seeded rows — no paging; documented here). `value` is the RAW stored string (FeatureFlag.Value verbatim), symmetric with the PUT body (what you GET is what you PUT back); the client's JSON preview displays it directly. No audit row on reads.
- DECISION (PUT response code): 204 No Content — consistent with every sibling admin write (T-011-05/07 return Results.NoContent()); the gherkin verifies the side effect via a follow-up read, not the response body.
- ASSUMPTION: concurrent edits use no optimistic concurrency — single-key PK last-write-wins is the contract (EC-011-1); each writer reads its own old value and writes its own new value, so both audit rows are correct for what each saw.
