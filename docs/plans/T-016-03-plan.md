## D-1: CREATE `src/core/ui/useFocusTrap.ts` (+ test)

A reusable focus-trap hook for modal dialogs. Behavior:
- On mount (or when container ref is set): save `document.activeElement`, focus the first focusable element inside the container (or a designated "initial" element via options).
- Trap Tab/Shift+Tab: on keydown, if Tab would exit the last/first focusable element, wrap to the opposite end.
- On unmount (cleanup): restore focus to the saved trigger element.
- Escape key closes (calls provided `onEscape` callback) — existing modals already handle Escape via their own listeners; this hook adds only the trap + restore.

```ts
export interface UseFocusTrapOptions {
  onEscape?: () => void
}
export function useFocusTrap(
  containerRef: RefObject<HTMLElement | null>,
  options?: UseFocusTrapOptions,
): void
```

Implementation notes:
- Query focusable elements via `container.querySelectorAll('button:not([disabled]), [href], input:not([type="hidden"]), select, textarea, [tabindex]:not([tabindex="-1"])')`.
- Store previous active element in a ref (set once on first effect run).
- Keydown listener attached to the container (capture phase for Tab).
- Cleanup: remove listener + `prevFocus.current?.focus()`.

**Test file:** `src/core/ui/useFocusTrap.test.tsx` — render a dialog with 3 buttons; assert initial focus on first button, Tab cycles through all 3 and wraps, Shift+Tab from first wraps to last, unmount restores focus to the trigger.
