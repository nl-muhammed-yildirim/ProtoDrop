# T-009-01 Implementation Plan

TASK: T-009-01 ListMyTransfersQuery + endpoint 14 owner-scoped list with cursor paging

GOAL: GET /api/v1/transfers returns the signed-in user's non-deleted transfers (OwnerAppUserId = session user), most recent first, cursor-paged at 25 rows per page (`?cursor={base64(created_at:id)}&limit=25` per TA-4.1.4), each row carrying the full US-009-01 happy-path payload — name (first file name or "Transfer"), FileCount, TotalBytes, recipient count, status, ExpiresAtUtc, DownloadsCount + MaxDownloads cap — with no extra round-trips per row (AC-009-1; TA-4.2#14).

## LIMITS & CONSTANTS CITED

- page-size = 25 — TA-4.1.4 pin (`?cursor={base64(created_at:id)}&limit=25`); NOT a Part 2 Limits Registry constant (registry checked: no transfers page-size entry).
- cursor format = base64(`{created_at:O}:{id:N}`) — TA-4.1.4 pin.
- IX_Transfer_Owner index on Transfer.OwnerAppUserId — TA-3.3, present in `src/wa.infrastructure/Persistence/Migrations/WaDbContextModelSnapshot.cs`.

## ERROR CODES

- UNAUTHENTICATED (401): session key `wa.session.userId` absent (guest hitting a signed-in-only endpoint) — existing member of the 18-member ProblemCodes closed list; NO new members added.
- VALIDATION (400): malformed cursor, or limit <= 0 / > 25 — existing member.

## MIGRATIONS

none (IX_Transfer_Owner already exists per TA-3.3).

## ASSUMPTIONS

- No new packages, no new ProblemCodes members, no schema changes.
- Row payload "download cap" = MaxDownloads column (int) on Transfer; download count = DownloadsCount — both already columns, no joins.
- Name derivation: first FileItem ordered by SortOrder then Id (`FileItem.OriginalName`); fallback literal `"Transfer"` when FileItems is empty.
