## Findings

[verified] **W3CTraceParser is strict W3C v00-only; malformed header never crashes the pipeline (AC-056-1)**
- `src/wa.domain/Correlation/W3CTraceParser.cs` — 50 ln, read fully. `Parse()` (lines 17–33) splits on `-`, requires exactly 4 parts (line 23), version must equal `"00"` (const line 7, checked at line 23), each hex field is validated by `IsAllHex` with exact lengths 2/32/16/2 **lowercase** only (lines 38–39); all-zero trace-id rejected as invalid per W3C (line 29). Malformed → `null`, which the middleware treats as absent and regenerates — EC-056-1 holds.
- Generated parentid: second random GUID's first 16 hex chars, flags `"07"` (`CorrelationMiddleware.cs` line 21) — both fields are independently random so no collision risk at M0 scale.
- `NewTraceId()` = `Guid.NewGuid().ToString("n")` (line 36) — exactly 32 lowercase hex; tested for shape and cross-call randomness in W3CTraceParserTests (97 ln, 24 test cases: 11 [Fact]/[Theory] markers → 9 facts + 3 InlineData rows on absent/blank theory + 12 InlineData rows on malformed theory = 24 invocations).

[verified] **CorrelationMiddleware is first in the pipeline and pushes both context values before any downstream middleware runs (FR-056-1)**
- `src/wa.api/Middleware/CorrelationMiddleware.cs` — 32 ln, read fully. `LogContext.PushProperty("CorrelationId", …)` + `PushProperty("TraceParent", …)` wrap the entire `_next()` call (lines 25–27), so every Serilog line including UseSerilogRequestLogging's per-request INF line carries both properties via FromLogContext enrichment — TA-10.5 holds without any explicit property in each log statement.
- Response header `TraceParent` is set before `_next()` too (line 28) — the "out" direction of TA-10.1 is satisfied even for requests that don't throw.
- No DI: ctor takes only `RequestDelegate next` — no config, no logger; ambient state lives in `CorrelationContext` (`AsyncLocal<TraceParent?>`, line 6 of CorrelationContext.cs), which falls back to a fresh 8-hex id when called outside a request (line 12) so ProblemWriter never writes a null correlationId.
